# Responsible Use Policy

## Purpose

This repository exists to **educate**, not to exploit.

It demonstrates how **metadata and timing side-channels** can leak information
in encrypted messaging systems using **simulations and models only**.

---

## Non-Negotiable Rules

By using, cloning, or contributing to this repository, you agree that:

### ✅ You WILL:
- Use the material for learning, research, or defense
- Run experiments only in controlled or simulated environments
- Target only systems and accounts you own or have explicit consent for
- Respect privacy, laws, and platform terms of service

### ❌ You WILL NOT:
- Target real users without consent
- Interact with production messaging services
- Modify this project to enable surveillance or tracking
- Use this work for harassment, stalking, or profiling
- Claim this project enables breaking encryption

---

## Explicit Scope Limitations

This project:
- Does **not** implement real messaging protocols
- Does **not** send messages to real phone numbers
- Does **not** bypass platform safeguards
- Does **not** deanonymize users
- Does **not** access message content

Any attempt to extend it beyond these boundaries
is **outside the intent of the authors**.

---

## Legal Considerations

Unauthorized monitoring of communication metadata may:
- Violate privacy laws
- Breach computer misuse statutes
- Conflict with platform terms of service

You are solely responsible for complying with applicable laws.

---

## Ethical Statement

Even metadata can reveal deeply personal information.

Understanding these risks is necessary to:
- Build safer systems
- Improve privacy protections
- Educate users and developers

Using such knowledge to harm others is unethical and unacceptable.

---

## Reporting Concerns

If you believe:
- A contribution crosses ethical boundaries
- Documentation enables misuse
- A simulation could be misunderstood

Please open an issue or contact the maintainers.

---

## Final Note

> Just because something is technically possible  
> does not mean it is ethically acceptable.

This project stands firmly on the side of **privacy, education, and responsible research**.
